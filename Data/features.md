# Twitter API Field Descriptions

| Field | Description |
|-------|-------------|
| `id/rest_id` | Internal Twitter user ID |
| `screen_name` | Twitter username (the part after @) |
| `name` | User's display name |
| `profile_image_url_https` | User's profile image URL (HTTPS protocol) |
| `profile_banner_url` | URL of the user's profile banner image |
| `description` | User's bio/self-introduction |
| `location` | User-specified location information |
| `created_at` | Account creation timestamp (UTC) |
| `followers_count` | Number of followers |
| `friends_count` | Number of accounts following |
| `statuses_count` | Total number of tweets |
| `favourites_count` | Number of likes given |
| `media_count` | Number of media items posted or retweeted |
| `listed_count` | Number of times added to others' lists |
| `pinned_tweet_ids_str` | List of pinned tweet IDs |
| `verified` | Traditional blue verification badge status |
| `is_blue_verified` | Twitter Blue subscription verification status |
| `default_profile_image` | Whether using default profile image |
| `default_profile` | Whether using default profile theme |
| `can_dm` | DM permission status for authorized user |
| `possibly_sensitive` | Whether account may contain sensitive content |
| `translator_type` | Translator account status identifier |
| `url` | Personal website URL in bio |
| `entities` | Entity information in bio (URLs, media, etc.) |
| `has_custom_timelines` | Custom timeline feature status |
| `fast_followers_count` | Number of fast followers (internal Twitter metric) |
| `withheld_in_countries` | List of countries where account is restricted |
